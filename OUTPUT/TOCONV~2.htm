Welcome

Welcome to all Toolbook Authors – world wide! ATUG (the Australian Toolbook User Group) is an international website dedicated to gathering info on using our favourite programming tool – Multimedia Toolbook.

This website is a little bit hard-core – yep – you are going to see code. Openscript programming is not simple - it takes skill. Toolbook programming however, is designed to be simpler than most other programing environments. We have lots of code snippets to help you.

I try to balance the code with animated training GIFS showing you a movie of specific procedures using Toolbook.

This web database has been put together by the members of the Australian Toolbook User Group, and consists of edited extracts from the Internet Forums discussing Toolbook - where various problems - and solutions - of authoring in Toolbook are exchanged - via the internet.

The tips on this site were generated with the assistance of "Toolbook Knowledge Nuggets" - a software package (freely downloadable) that lets you read everything that's ever been said about authoring & programming Toolbook on the internet. It is available from:
